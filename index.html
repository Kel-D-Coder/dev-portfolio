About me

I build software that earns its keep

I’m a full-stack web developer focused on shipping scalable, high-performance applications end to end. I care about the details users actually feel. fast loads, obvious interfaces, and flows that don’t break under real traffic.

On the front end I work with React, Next.js, TypeScript and TailwindCSS. On the back end I build reliable APIs with Node.js, Express and MongoDB, including authentication, payments and third-party integrations.

Whether it’s a SaaS platform, an automation tool or a storefront for a client, I work like a teammate: clear communication, sensible tradeoffs, and code the next developer can actually read.
